# PCB

KiCad design for the micromouse's custom PCB

| File | Contents |
| :--- | :--- |
| `MicromouseProject.kicad_pro` | KiCad project file — open this first |
| `MicromouseSch.kicad_sch` | Schematic |
| `MicromousePCB.kicad_pcb` | PCB layout/routing |

Rendered schematic and board images are in [`Assets`](../Assets/) and shown in the [top-level README](../README.md#cad-and-pcb-models).

Requires [KiCad](https://www.kicad.org/) to open and edit.
